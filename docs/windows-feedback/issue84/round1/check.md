# 第 1 轮 Always UI check

在 Windows 11 的 Tauri 窗口中检查，WebView2 为 157，显示缩放为 175%，内容视口为 1191 × 791 CSS px。改动前使用提交 `8ae2f96` 的前端生产资源，改动后使用内置资源的 Tauri 构建。两次均连接同一个环回服务，使用同一份合成聊天记录。

`design` 采用消息应用布局。会话记录占据可伸缩空间，单行胶囊把附件、编辑区和发送组织在一行。输入扩展时三个区域保持独立列。按安装的 Always UI 阅读了设计原型、数值预设、视觉纪律、实现说明和检查目录，并从上游补读设计强度说明。复用 Lavender、`--panel`、`--shadow`、`--edge-fade`、现有控件尺寸和浮动标签。圆角取预设的 24 px，六行上限按已有行高计算。

| 程度 | 位置 | 观察与影响 | 整改 | 实测 |

| P2 · C05/C06 | 空输入区 | 原编辑区 56 px，提示与左右按钮的视觉中心分离 | 输入区单行起步，三列居中，柔和投影集中在胶囊 | 新编辑区 36 px，外框约 47 px。聚焦前后外框尺寸一致，1 px 边框变色。[改动前](../before/wide-idle.png) · [改动后](wide-idle.png) · [聚焦](wide-focus.png) |
