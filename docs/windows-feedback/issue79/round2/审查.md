# 第二轮 Always UI check

客户端重新启动后独立采图。wide 为 1130 × 610 CSS px，narrow 为 501 × 610 CSS px，物理显示缩放 175%。每个尺寸均重新进入聊天、通讯录、文件和设置。原生窗口截图包含系统合成的背景。输入、触控事件及键盘操作在该客户端内执行，测试资料仅含本机合成数据。

| 程度 | 位置 | 观察 | 用户影响 | 最小整改 | 复验状态 |
| --- | --- | --- | --- | --- | --- |
| 首轮 C06 | 通讯录分栏与资料行 | 分栏的纵向渐隐与行线的横向渐隐均为两端 8px | 列表与详情保持层次 | 复用分界线 Token | 已读取真实窗口的横纵渐变值 |
| 首轮 C12 | 滚动条 | 滑块在悬停时为 16% 黑，离开后为透明 | 可阅读内容，不妨碍滚动操作 | 滚动容器直接使用 scrollbar-color | 已复验。键盘翻页 425 CSS px，WebView2 触控滑动 97 CSS px |
| 首轮验收缺口 | 消息选择 | WebView 调试鼠标没有选中文字；Win32 鼠标实际拖选得到「界面验收」 | 正文可以复制 | 用原生鼠标及 Ctrl+C / Ctrl+V 验证草稿内容 | 粘贴值与选中文字一致，见 selected-message.png |
| 第二轮 C06 | 自己的资料弹窗 | 旧的局部 2px 行线覆盖了通用样式 | 行线与其他列表不一致 | 统一行线宽度 | 已再次启动客户端，校验两条线并采图 profile-recheck.png |
| 第二轮 C11 | 文件筛选 | 原生 select 沿用额外的聚焦外框 | 输入类控件聚焦表现不同 | 复用现有柔和阴影和边框颜色，保留强制颜色焦点 | 原生窗口实测宽高相等，见 file-filter-recheck.png |

- 全部页面沿用同一导航底层与内容表面，未见重复卡片或边缘阴影。底层实测 alpha 0.75，外围两层 box-shadow 均为 none。Lavender 保留给选中态和操作，正文选择使用中性灰。
- 三处搜索在宽窗左上角均为 (72, 44)，窄窗均为 (73, 44)。输入框高 36，聚焦前后矩形一致。会话行渐隐从头像区域开始，至右侧列表内边距。
- 两种尺寸下，通讯录与文件顶部、中段、底部的渐隐宽度分别为 (0, 8)、(8, 8)、(8, 0)。长草稿同样通过。实测设置助理页在本次宽窗中内容恰好容纳，底部渐隐为 0。
- 原生标题栏拖动位移 (40, 24) 物理像素；最大化、还原、关闭提示、Escape 取消均正常。WebView2 强制颜色及减少动态效果模拟中，键盘焦点保留实线轮廓，过渡时长为 0。
- 未在物理触屏、其他 Windows 版本或其他缩放档位实测。隔离测试没有连接公网账号，未重新执行跨设备 M2 或云端 M3 验收。
