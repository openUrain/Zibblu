# 界面设计准则

先确认本次涉及的页面、状态和平台。在改动范围内复用项目已有的设计令牌与组件语义，按下列规则做设计、实现或评审。

## 层级、边界和圆角

- **微明度色阶**。用同色系的小幅明度差区分页面背景、侧栏、卡片和内嵌区域。普通容器靠表面色与留白分层，默认无边框。
- **单层边框**。需要轮廓时，从外往内任意一条经过嵌套组件的视线最多穿过一层描边。框内按钮用底色变化表达悬停和按下，边框保持为零。需要分隔线或描边时按 2px 绘制。
- **双环阴影**。输入框聚焦、控件选中时，用内紧外柔的两层阴影加深状态，已有边框的颜色轻微偏向主题色。无边框的控件用双环阴影表达状态。常规主题下用这套样式替代 `outline`。键盘焦点必须清晰可辨，避免焦点提示与持久选中状态混淆，高对比模式下保留可见的焦点反馈。
- **渐变曲率**。所有圆角用连续曲率，直边到转角平滑过渡。复用项目已有的连续圆角实现，或使用平台支持的平滑圆角能力。
- **同心圆角**。嵌套圆角共用对齐的角部轮廓，外圆角半径等于内圆角半径加两层轮廓的可见间距。比如内半径 12px、缝宽 4px，外半径取 16px。内外两层保持相同的曲率轮廓类型。

## 排版和文件名

- **单页字号最多四档**。合并相近字号，用已有字重、明度和留白表达层级。
- **私密聊天暗色字重**。私密聊天的暗色区域统一以对应字重的约 90% 起调，例如 400 调到约 360。优先用可变字体的字重轴，遇到离散字重时按实际观感选取，目标是在亮底和暗底看起来一样重。
- **数字等宽**。界面数字统一启用 `font-variant-numeric: tabular-nums` 或平台等效特性，实际使用的字体须支持等宽数字。检查时钟、计数和数据列，确保位数相同时换数字不引起横向跳动。
- **文件名截断**。空间不足时只截断主文件名，把省略号放在扩展名前，例如 `设计稿最终….fig`。先给扩展名留出空间。保留原始名称供复制和完整查看。无扩展名时按普通文本在末尾截断。

## 控件和状态

| 组件 | 适用场景 |
| --- | --- |
| 开关 | 同一功能的开与关，切换后立即生效。用开启时成立的正向短语作标签，例如「接收通知」。中文标签优先四字以内，最多六字。 |
| 勾选框 | 独立勾选、多个选项可同时选中，或勾选后再随表单提交，例如「确定」。 |
| 单选框 | 一组互斥选项需要同时展示，从中只选一项，例如「仅今天」或「始终」。 |
| 下拉菜单 | 集合操作命令，例如「重命名」「下载」。触发器保留动作入口。 |
| 选择器 | 为字段挑选一个或多个值，例如选择语言。触发器展示当前值或未选择提示。 |

- **状态反馈**。操作反馈文字默认隐藏，只在实际状态变化时出现。用能直接读出进度、结果或下一步的短句，例如「正在上传头像…」「头像已更新」「上传失败，请重试」。在操作附近用醒目的图标和有对比度的提示样式承载文字。成功可以短暂显示，失败保持可见，直到用户能处理或重新尝试。

## 动效和窗口

- **自适应展开**。折叠区用网格轨道从 `0fr` 过渡到 `1fr`，由内容决定最终高度。裁切发生在可收缩的内层，收起时其中的控件退出键盘导航。禁止用脚本测量、写入或逐帧修改容器高度。验证多行文本和异步增加的内容都能自然撑开。
- **抽屉动效**。Drawer 快速弹入、短促回收。允许打开时有轻微回弹，快速反向操作时从当前位置继续。系统要求减少动态效果时，保留即时的状态切换。
- **桌面窗口拖拽**。让侧栏与顶栏连成连续的窗口表面，沿用当前产品的样式。两处的空白区域都能通过宿主的窗口拖拽能力移动整窗。导航项、输入框、滚动区和窗口按钮继续响应各自的交互。

## 验收

逐条检查本次涉及的规则。用实际界面或可运行预览检查静止状态、键盘焦点、选中及状态变化，再覆盖适用的多行展开、快速开合、暗色私密聊天、窄栏长文件名和桌面拖拽。评审时指出具体位置、违反的规则和可观察到的改动目标。未运行的交互标记为待验证。
